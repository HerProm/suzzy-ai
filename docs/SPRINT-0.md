# SPRINT 0 - Fundação técnica do projeto

## Objetivo
Preparar a base técnica do projeto SUZZY AI, sem iniciar qualquer funcionalidade de produto.

## Checklist de tarefas pequenas e objetivas

### 1. Inicializar o projeto
- Criar a aplicação Next.js com TypeScript.
- Configurar Tailwind CSS.
- Usar App Router como estrutura principal.

### 2. Configurar qualidade de código
- Configurar ESLint no projeto.
- Validar a configuração inicial do lint.

### 3. Preparar variáveis de ambiente
- Criar o arquivo `.env.example` com as variáveis esperadas para o ambiente local.
- Documentar quais valores devem ser preenchidos pelo desenvolvedor.

### 4. Organizar a estrutura mínima de pastas
- Criar a estrutura inicial do projeto.
- Definir as pastas essenciais para app, components, lib e public.
- Manter a organização simples e evitável.

### 5. Validar execução local
- Confirmar que `npm run dev` funciona corretamente.
- Confirmar que a aplicação sobe localmente sem erros básicos.

### 6. Validar lint
- Confirmar que `npm run lint` funciona corretamente.
- Garantir que o projeto entra em uma base de qualidade mínima.

### 7. Preparar o repositório
- Inicializar o Git no projeto.
- Definir o estado inicial do repositório.
- Preparar a base para continuidade do desenvolvimento.

### 8. Documentar execução local
- Registrar no repositório como rodar o projeto localmente.
- Incluir comandos básicos de instalação, execução e verificação.

## Critério de conclusão do Sprint 0
O Sprint 0 estará concluído quando:
- o projeto estiver inicializado com Next.js, TypeScript, Tailwind CSS e App Router;
- ESLint estiver configurado;
- o arquivo `.env.example` estiver criado;
- a estrutura mínima de pastas estiver pronta;
- `npm run dev` estiver funcionando;
- `npm run lint` estiver funcionando;
- o repositório Git estiver preparado;
- a execução local estiver documentada.

## Escopo excluído do Sprint 0
Não devem ser implementados neste sprint:
- Supabase;
- autenticação;
- dashboard;
- integração com IA;
- persistência;
- funcionalidades do produto.

## Regra de execução
Nenhuma funcionalidade de produto deve entrar no Sprint 0. O objetivo deste sprint é apenas preparar a fundação técnica do projeto para as próximas etapas.
